# 나만의 퀴즈 게임 GUI 확장판

이 폴더는 완성된 터미널 퀴즈 게임을 `PySide6` 데스크톱 화면으로 연결한
별도 확장판입니다. 기존 `main.py`, `quiz.py`, `game.py`는 수정하지 않습니다.

## 구현 기능

- 풀 문제 수 선택과 겹치지 않는 무작위 출제
- 선택지 버튼 채점과 정답·오답 안내
- 힌트 보기와 1회당 5점 차감
- 퀴즈 추가, 정답 번호와 선택적 힌트 입력
- 정답을 노출하지 않는 퀴즈 목록
- 확인 대화상자를 거치는 퀴즈 삭제
- 최고 점수와 최근 게임 기록 5개 표시
- 기존과 같은 UTF-8 `state.json` 저장·불러오기와 손상 복구
- 종료 버튼, 창 닫기, 터미널의 `Ctrl+C`에서 안전 저장

## 가장 쉬운 실행 방법

`release/QuizGameGUI-macOS-Intel.zip`을 풀고 `QuizGameGUI.app`을 더블 클릭합니다.
같은 폴더의 `state.json`이 앱의 데이터 파일입니다.

공용 iMac에서 처음 열 때 macOS 경고가 나오면 앱을 우클릭한 뒤 **열기**를 선택합니다.
직접 만든 서명되지 않은 학습용 앱이기 때문에 나타날 수 있는 확인 절차입니다.

## 소스로 실행하는 방법

Python 3.10 이상으로 프로젝트 루트에서 다음 순서로 실행합니다.

```bash
python3 -m venv .gui-venv
source .gui-venv/bin/activate
python -m pip install PySide6
python -m gui.app
```

가상환경은 이 프로젝트만의 라이브러리 공간이므로 관리자 권한이 필요하지 않습니다.

## 초보자가 설명할 핵심 3가지

1. **위젯:** 라벨, 버튼, 입력칸처럼 화면에 놓는 부품입니다.
2. **레이아웃:** 위젯을 가로 또는 세로로 정렬하는 보이지 않는 정리 상자입니다.
3. **클릭 신호 연결:** 버튼의 `clicked` 신호를 실행할 메서드에 연결합니다.

```python
start_button.clicked.connect(self.start_quiz)
```

뜻은 “시작 버튼을 클릭했다는 소식이 오면 `start_quiz` 메서드를 실행하라”입니다.

## 파일 역할

- `core.py`: JSON, 퀴즈 규칙, 점수와 게임 기록
- `app.py`: 창, 위젯, 레이아웃과 클릭 연결
- `test_core.py`: 핵심 기능 자동 검증
- 프로젝트 루트의 `quiz.py`: 기존 `Quiz` 클래스를 그대로 재사용
