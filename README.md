# 🎯 나만의 퀴즈 게임 (터미널 퀴즈 게임)

## 1. 프로젝트 개요

파이썬(Python) 기본 문법과 깃(Git)을 익히기 위해 만든 터미널 퀴즈 게임입니다.
메뉴에서 번호를 골라 퀴즈 풀기·추가·목록·삭제·점수 확인을 할 수 있고,
프로그램을 껐다 켜도 퀴즈와 점수가 `state.json` 파일에 남아 유지됩니다(데이터 영속성).
코드는 "퀴즈 한 문제"를 표현하는 `Quiz` 클래스와, 게임 전체 흐름을 관리하는
`QuizGame` 클래스로 역할을 나눠 구성했습니다.

## 2. 퀴즈 주제와 선정 이유

- 주제: 파이썬과 깃 기초 상식
- 선정 이유: 코디세이 진행중에 게임을 플레이 하는 것만으로도 매주 보는 시험 범위를 자연스럽게 복습할 수 있도록, 학습 내용 자체를 퀴즈 주제로 골랐습니다.

## 3. 실행 방법

1. 파이썬 3.10 이상이 필요합니다. 확인: `python3 --version`
2. 터미널에서 이 프로젝트 폴더로 이동합니다.
3. 다음 명령으로 실행합니다.

```
python3 main.py
```

- 별도로 설치할 외부 라이브러리는 없습니다. (표준 라이브러리 `json`, `random`, `datetime`만 사용)

## 4. 기능 목록

| 메뉴 | 기능 | 설명 |
|---|---|---|
| 1 | 퀴즈 풀기 | 풀 문제 수를 고르면(보너스) 무작위로 문제를 뽑아(보너스) 출제. 각 문제에서 `0`을 입력하면 힌트를 보여주며, 힌트 1회당 5점 차감(보너스) |
| 2 | 퀴즈 추가 | 문제·선택지 4개·정답 번호·힌트(선택)를 입력해 등록하고 파일에 저장 |
| 3 | 퀴즈 목록 | 등록된 문제 목록 확인 (정답은 표시하지 않음) |
| 4 | 퀴즈 삭제 | 번호를 고르고 `y/n` 확인을 거쳐 삭제, 파일에 반영 (보너스) |
| 5 | 점수 확인 | 최고 점수와 최근 게임 기록(날짜·문제 수·점수, 보너스) 표시 |
| 6 | 종료 | 저장 후 안전 종료. `Ctrl + C`를 눌러도 저장 후 안전 종료 |

**입력 처리 규칙(공통):** 입력 앞뒤 공백 제거, 빈 입력·숫자가 아닌 입력·범위 밖 숫자는
안내 문구를 보여주고 다시 입력받습니다.

**점수 규칙:** 점수 = (맞힌 수 ÷ 푼 문제 수 × 100, 반올림) − (힌트 사용 횟수 × 5), 최저 0점.

## 5. 파일 구조

```
python-quiz-game/
├── main.py            # 시작점: QuizGame을 만들고 실행만 한다
├── quiz.py            # Quiz 클래스: 문제 1개의 속성(문제·선택지·정답·힌트)과 동작
├── game.py            # QuizGame 클래스: 메뉴·풀기·추가·목록·삭제·점수·저장/불러오기
├── state.json         # 데이터 파일 (프로그램이 자동 생성·관리)
├── README.md          # 이 문서
├── .gitignore         # 깃 제외 목록 (파이썬 임시 파일, 맥 시스템 파일 등)
└── docs/screenshots/  # 제출용 실행 화면 캡처
```

## 6. 데이터 파일 설명 (state.json)

- **경로:** 프로젝트 루트의 `state.json`
- **역할:** 퀴즈 목록, 최고 점수, 게임 기록을 저장해 프로그램 재시작 후에도 유지
- **인코딩:** UTF-8 (`ensure_ascii=False`로 저장해 한글이 그대로 보임)
- **안전 장치:** 파일이 없으면 기본 퀴즈 5개로 시작하고, 손상되어 있으면 안내 후
  기본 퀴즈로 복구합니다. `Ctrl + C`로 중단해도 저장 후 종료합니다.

**필드(스키마) 구조:**

| 열쇠 | 자료형 | 뜻 |
|---|---|---|
| `quizzes` | 리스트 | 퀴즈 목록. 각 항목은 `question`(문자열) / `choices`(문자열 4개 리스트) / `answer`(정수 1~4) / `hint`(문자열 또는 null) |
| `best_score` | 정수 또는 null | 최고 점수. 아직 안 풀었으면 null |
| `history` | 리스트 | 게임 기록. 각 항목은 `date`(문자열) / `total`(정수) / `correct`(정수) / `score`(정수) |

예시:

```json
{
  "quizzes": [
    {
      "question": "파이썬의 창시자는?",
      "choices": ["리누스 토르발스", "귀도 반 로섬", "제임스 고슬링", "브렌던 아이크"],
      "answer": 2,
      "hint": "네덜란드 출신입니다."
    }
  ],
  "best_score": 95,
  "history": [
    { "date": "2026-07-30 14:20", "total": 3, "correct": 3, "score": 95 }
  ]
}
```

> 참고: 실무에서는 데이터 파일을 `.gitignore`에 넣어 깃 추적에서 빼는 경우도 많지만,
> 이 과제에서는 시연과 채점 확인이 쉽도록 저장소에 포함했습니다.
